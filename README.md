# ML Business Center

Projet de démonstration d'un site dynamique de réservation d'espaces professionnels.

## Fonctionnalités
- Interface marron / blanc / beige
- Responsive téléphone, tablette et ordinateur
- Catalogue dynamique des espaces
- Filtres par type
- Formulaire de réservation interactif
- Calcul automatique du prix
- Options supplémentaires
- Confirmation de réservation
- Sauvegarde des réservations dans `localStorage`
- Animations au scroll
- Menu mobile
- Galerie responsive
- Images locales, sans dépendance à un CDN pour les photos

## Lancer le projet
Ouvre simplement `index.html` dans un navigateur.

## Modifier les espaces
Les espaces, prix, capacités et images sont dans `js/script.js`, dans le tableau `spaces`.

## Images
Toutes les photos sont placées dans `images/`.
